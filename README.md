# Portfolyo
# Kişisel Portfolyo Web Sitesi 🚀

Ankara Yıldırım Beyazıt Üniversitesi Bilgisayar Mühendisliği öğrencisi olarak geliştirdiğim, kendimi, projelerimi ve sertifikalarımı sergilediğim modern ve responsive kişisel portfolyo web sitem.

🔗 **Canlı Siteyi İnceleyin:** [zhrbayraktr.github.io/Portfolyo](https://zhrbayraktr.github.io/Portfolyo/)

---

## 🛠️ Kullanılan Teknolojiler

Aşağıdaki frontend teknolojileri ve araçlar kullanılarak saf (pure) kodlama ile geliştirilmiştir:

- **HTML5** - Semantik sayfa mimarisi ve iskeleti
- **CSS3** - Modern, asil saf siyah ve mavi tonlarında premium karanlık (dark) tema tasarımı
- **JavaScript (ES6+)** - Dinamik daktilo (typing) efekti ve geliştirici konsolu (console) etkileşimi
- **Git & GitHub** - Sürüm kontrolü ve GitHub Pages üzerinden ücretsiz yayınlama

---

## ✨ Öne Çıkan Özellikler

- **Dinamik Daktilo Efekti:** JavaScript mimarisi kullanılarak unvanların canlı olarak yazılıp silindiği akıcı arayüz.
- **Akademik Projeler:** Yürütülmekte olan **TÜBİTAK 2209-A** projesinin kurumsal sergilenmesi.
- **Sertifika Alanı:** BTK Akademi, Bilişim Vadisi ve Gençlik ve Spor Bakanlığı gibi prestijli kurumlardan alınan siber güvenlik ve yapay zeka sertifikalarının grid düzeni.
- **Konsol Sürprizi:** Sitenin kaynak kodlarını inceleyen geliştiriciler için tarayıcı konsoluna bırakılmış özel CSS log mesajı.
